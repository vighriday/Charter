# The four type files in this folder

Two families, four files, both free to use, redistribute and embed. Fetched once by
`node scripts/fonts.mjs` and committed here so the website needs nothing from
anybody once it is open.

Only the latin part of each face was taken, which is the part this site uses. That
part also covers the curly apostrophe and the em dash, so the record's own words and
the agreement can be quoted exactly as they were written.

| File | Family | Designed by | Licence |

| `newsreader-roman.woff2` | Newsreader, upright, variable optical size, weight 400 | Production Type | SIL Open Font License 1.1 |
| `newsreader-italic.woff2` | Newsreader, slanted, variable optical size, weight 400 | Production Type | SIL Open Font License 1.1 |
| `plexmono-400.woff2` | IBM Plex Mono, weight 400 | Mike Abbink and Bold Monday, for IBM | SIL Open Font License 1.1 |
| `plexmono-500.woff2` | IBM Plex Mono, weight 500 | Mike Abbink and Bold Monday, for IBM | SIL Open Font License 1.1 |

## What that licence allows and asks

The SIL Open Font License lets anybody use these files for anything, including
commercially, and lets them be bundled and redistributed exactly as they are here.
It asks two things in return, and both are met by this folder existing:

1. The files are not sold on their own. They are not.
2. This notice travels with them.

It also says a modified version must be released under the same licence and must not
use the original's reserved name. Nothing here is modified. These are the files as
they were published, with the parts this site does not use left out, which the
licence permits.

The full text of the licence is at <https://openfontlicense.org>. Newsreader is
published at <https://github.com/productiontype/Newsreader> and IBM Plex at
<https://github.com/IBM/plex>.

## Why these two

Newsreader was drawn for reading on a screen at ordinary sizes, and its optical size
axis means the same file can be set at 44 points for a heading and at 17 for a note
without either looking like the other stretched. This site sets it at 400 and never
heavier, so the bold file is deliberately absent rather than merely unused.

IBM Plex Mono is the record's face. Every entry, every fingerprint and every count is
set in it, and its figures are the same width as each other, so 154 rows of numbers
line up in a column instead of shifting as the values change.
